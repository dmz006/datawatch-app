This app is a client for a self-hosted datawatch server and has no developer-run backend. Please use the demo server URL (user name field) and API token (password field) supplied in Sign-in information. In the app: Settings tab › Comms › Servers › +, paste the URL and token, tap Add, then open the Sessions tab. Full walkthrough: https://github.com/dmz006/datawatch-app/blob/main/docs/ios.md#first-run
